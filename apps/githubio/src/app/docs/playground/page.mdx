# Playground 2.0: Streaming, Vision & Media Studio

**Playground 2.0** (available at `/playground` in the Next.js dashboard) is an interactive multimodal workbench for real-time SSE streaming, routing telemetry inspection, Vision image attachments, ComfyUI media synthesis, side-by-side A/B model benchmarking, and fine-tuning dataset curation.

---

## Interactive Workbench Modes

Playground 2.0 exposes rich diagnostic metadata and specialized testing modes:

- **Real-Time SSE Streaming Speedometer**: Streams tokens live (`stream: true`) with instantaneous **TTFT (ms)**, **throughput (tok/s)**, complexity tier, and `X-Eluvix-*` response header badges.
- **Multimodal Vision Dropzone & Clipboard Paste**: Drag-and-drop PNG/JPEG/WEBP files onto the composer, paste screenshots directly from your clipboard, or click the `📎` attachment button to send OpenAI `image_url` payloads to vision-capable models (`gemini-4-carbon`, `gpt-4o`, `llava`, `Qwen2-VL`).
- **Image / Media DAG Studio (`🎨 Image / Media Studio`)**: Dedicated ComfyUI synthesis mode targeting `POST /api/v1/images/generations` with workflow preset selector (`flux-txt2img`, `sdxl-txt2img`, `wan21-txt2vid`, `hunyuan3d-mesh`), aspect ratio pills (`1024x1024`, `1344x768`, `768x1344`), seed input, negative prompt, and one-click asset download.
- **A/B Split Arena (`⚔️ A/B Arena`)**: Dispatches the exact same prompt in parallel to **Model A** (e.g. `gemini-4-carbon-high`) and **Model B** (e.g. local RamaLama or Ollama), comparing latency, tok/s, token count, and estimated USD cost side-by-side.
- **Reasoning & Code Renderer**: Automatically renders collapsible `<think>...</think>` reasoning trace accordions and syntax-badged fenced code blocks with one-click copy buttons.

## Session Persistence

All playground conversations are automatically committed to the local SQLite database (`chat_history` table).

You can:
- Switch between active conversation threads.
- Inspect raw request and response payloads.
- Re-run specific prompts with alternative temperature or system instruction parameters.

## Exporting Fine-Tuning Datasets (JSONL)

High-quality local conversations can be converted into ready-to-train datasets with a single click or API call.

### One-Click UI Export

In the Playground, click **"Export Dataset"** to download an `.jsonl` file formatted to the OpenAI Fine-Tuning standard:

```json
{"messages": [{"role": "system", "content": "You are a helpful assistant."}, {"role": "user", "content": "Explain latency spillover."}, {"role": "assistant", "content": "Latency spillover routes requests..."}]}
```

### Programmatic Export Endpoint

You can also fetch exported datasets via the REST API:

```bash
curl -k https://127.0.0.1:3588/api/v1/export \
  -H "Authorization: Bearer <ADMIN_PASSWORD>" \
  -o fine_tuning_dataset.jsonl
```

The resulting file can be fed directly into fine-tuning pipelines (such as Axolotl, Unsloth, LLaMA-Factory, or OpenAI fine-tuning) to distill cloud model outputs into small local models.
