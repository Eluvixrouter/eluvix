# Native Tools & Agent Gateways

Eluvix is an agent-ready orchestration gateway. It allows developers and operators to bind external capabilities directly into model reasoning loops through native tools, Model Context Protocol (MCP) servers, and secure Agent Gateways.

---

## Agent Gateway Node (`agentGatewayNode`)

The **Agent Gateway** acts as a security boundary between language models and external tool execution environments:

### Access Policies
- **Restrictive (`restrictive`)** *(Recommended)*: Only explicitly connected and whitelisted tools can be called by models.
- **Permissive (`permissive`)**: Allows models to query approved internal VPC tool services.
- **Open (`open`)**: Connects to public MCP registries for broad capability discovery.

### Tool Filtering Modes
- **Allow All (`all`)**: Exposes all connected tools to the LLM's function declaration manifest.
- **Strict Whitelist (`whitelist`)**: Filters declarations down to an approved subset of functions.
- **Blacklist Risky Tools (`blacklist`)**: Suppresses destructive tools (e.g. `rm`, `drop_database`, `execute_arbitrary_shell`).

### Output PII Sanitization
When enabled, tool execution results are passed through the **Privacy Guard** before being returned to the model context. This prevents database queries or web scraper output from introducing external PII into subsequent reasoning turns.

### Tool Execution Timeouts
Operators can configure granular execution timeout windows (e.g. `10,000ms`) per gateway, preventing stalled third-party APIs from hanging agent loops.

### OpenBao Secret Injection
Eluvix integrates with **OpenBao / HashiCorp Vault** secret engines (`/api/secrets/discover`). The Agent Gateway can automatically inject decrypted API keys or bearer tokens into outbound tool requests without exposing credentials in client canvases or client responses.

## Model Context Protocol (MCP)

Eluvix natively supports the **Model Context Protocol (MCP)**—acting both as an MCP client/gateway to external tool servers and as a **Sovereign MCP `2025-06-18` Server** that exposes Eluvix's own routing intelligence, DLP scrubber, memory engine, and ComfyUI synthesis to Claude Desktop, Cursor, Windsurf, Google Antigravity (`agy`), OpenCode, and Codex CLI.

### 1. Eluvix Native Sovereign MCP Server (`POST /api/v1/mcp` & `npx eluvix-mcp`)
External AI IDEs and agents can connect to Eluvix over two transports:
- **Streamable-HTTP JSON-RPC 2.0**: `POST https://127.0.0.1:3588/api/v1/mcp` (authenticated via `Authorization: Bearer` or `x-api-key`).
- **Stdio CLI Binary**: `npx eluvix-mcp` (pure NDJSON over `stdout` with diagnostic logs routed to `stderr` so JSON-RPC frames are never corrupted).

| Sovereign MCP Tool | Capability |
| :--- | :--- |
| `eluvix_route_explain` | Dry-runs Switchyard complexity, modality, and budget routing without invoking an upstream (`\$0.00`). |
| `eluvix_list_models` | Lists configured local & cloud models with capability tags and per-1k token pricing. |
| `eluvix_smart_complete` | Dispatches a completion through PrivacyGuard, SemanticGuard, and Switchyard (increments `x-eluvix-hops`; blocks recursion when `hops >= 2`). |
| `eluvix_memory_query` | Queries user-scoped recall across OpenViking, Graphiti, LightRAG, Mem0, or SQLite FTS5. |
| `eluvix_memory_store` | Persists curated facts or preferences to the caller's scoped memory store. |
| `eluvix_privacy_scrub` | Redacts API keys, SSNs, emails, credit cards, and custom regexes from untrusted text. |
| `eluvix_generate_image` | Synthesizes local images/video/3D assets via ComfyUI (`flux-txt2img`, `sdxl-txt2img`, `wan21-txt2vid`, `hunyuan3d-mesh`). |

Eluvix also serves read-only MCP resources (`eluvix://config/summary` with `apiKey` fields stripped, `eluvix://telemetry/spend-24h`, and `eluvix://upstreams/health`).

### 2. MCP Tool Node (`mcpToolNode`)
The visual editor provides dedicated MCP Tool nodes:
- **Server Endpoint**: Connects via Server-Sent Events (SSE) or local standard I/O (stdio).
- **Execution Modes**:
  - **Automatic (`auto`)**: Executes tool calls immediately upon model request.
  - **Human-in-the-Loop (`confirm`)**: Halts execution and presents a confirmation modal before running potentially dangerous actions.
  - **Dry Run (`dry-run`)**: Simulates tool execution and returns a mocked response for safe evaluation.
- **Parameter Validation**: Automatically verifies model-supplied arguments against JSON schema definitions before network dispatch.

### Execution Backend Modes
- **Auto (`auto`)**: Attempts to connect once on startup to a live desktop session and automatically falls back to the in-process headless CPU renderer if no GUI is listening.
- **Remote Desktop GUI (`remote`)**: Automatically selects the exact remote flag per application (`--connect` for VectorCraft/LightCraft/DesignCraft/WordCraft/SoundCraft/DeckCraft/CADCraft/GridCraft, `--bridge` for PhotoCraft/FilmCraft/EffectCraft, `--attach` for FigCraft).
- **Headless CPU Renderer (`headless`)**: Runs an in-process document model and CPU renderer with no window or display server required (remote UI-only tools such as `ui_screenshot`, `wait_for_changes`, and `ui_click` are automatically filtered out).

### Filesystem Confinement (`--automation-read-root` & `--automation-write-root`)
- Operators can restrict file open, import, place, save, and export operations to explicit directory trees via **Read Root** and **Write Root**.
- When `remote` mode is selected alongside confinement roots, Eluvix's compiler automatically places the remote flag (`--connect` / `--bridge` / `--attach`) on `<app>-cli mcp` and emits the `--control <port> --automation-read-root ... --automation-write-root ...` flags for the desktop GUI launch command.

### Built-in MCP Workflow Presets
- **VectorCraft Presets**: `poster`, `icon-set`, `recolor`, `trace-and-style`, `export-set`.
- **FigCraft Presets**: `mobile_screen`, `design_system`, `landing_page`, `prototype_flow`, `fix_comments`, `watch_comments`.

### Context Enrichment & Domain Guardrails
When `vectorcraftNode` or `artcraftNode` is active on a route, `@eluvix/router-core` injects `<eluvix-vectorcraft-mcp>` / `<eluvix-artcraft-mcp>` system instructions and emits `x-eluvix-artcraft-apps`, `x-eluvix-artcraft-mode`, `x-eluvix-artcraft-protocol`, and `x-eluvix-artcraft-detected` response headers:
- **VectorCraft Coordinate & Opacity Rules**: Document points (`612 x 792` US Letter default, origin `(0, 0)` top-left, `y` downward) and `opacityPct` (`0..100%`) on all drawing/mutation calls (`draw_shape`, `draw_path`, `object.setProps`, `transparency.set`), with `command_batch` step result interpolation (`"step0.id"` / `"last.id"`).
- **CADCraft Mathematical Geometry Verifiers**: Agents verify drafted geometry using `execute {"command": "shapes"}` (exact perimeter, area, centroid, self-intersections) and `execute {"command": "loops"}` before calling `render`.
- **Craft Anything Clean-Room Rebuilds**: Agents inspect binaries and Electron/web bundles via 284 tools across `core`, `web`, `javascript`, `runtime` (GDB/Rizin), `frida`, `application`, `database`, and `build`, paging through large decompilation evidence via `core_evidence_browse`.

## Native Built-in Tools

Eluvix includes zero-dependency native tools served directly from `/api/v1/tools`:

### 1. Calculator
- Evaluates arithmetic and mathematical expressions securely without executing arbitrary code.
- Ideal for small or fast reasoning models requiring exact numerical precision.

### 2. Web Scraper
- Fetches external URLs, strips boilerplate HTML markup, and extracts clean, readable markdown or plain text.
- Formats extracted content directly into the model's context for summarization or comparative analysis.
