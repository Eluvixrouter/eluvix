# Native Tools & Agent Gateways

Eluvix is an agent-ready orchestration gateway. It allows developers and operators to bind external capabilities directly into model reasoning loops through native tools, Model Context Protocol (MCP) servers, and secure Agent Gateways.

---

## Agent Gateway Node (`agentGatewayNode`)

The **Agent Gateway** acts as a security boundary between language models and external tool execution environments:

### Access Policies
- **Restrictive (`restrictive`)** *(Recommended)*: Only explicitly connected and whitelisted tools can be called by models.
- **Permissive (`permissive`)**: Allows models to query approved internal VPC tool services.
- **Open (`open`)**: Connects to public MCP registries for broad capability discovery.

### Tool Filtering Modes
- **Allow All (`all`)**: Exposes all connected tools to the LLM's function declaration manifest.
- **Strict Whitelist (`whitelist`)**: Filters declarations down to an approved subset of functions.
- **Blacklist Risky Tools (`blacklist`)**: Suppresses destructive tools (e.g. `rm`, `drop_database`, `execute_arbitrary_shell`).

### Output PII Sanitization
When enabled, tool execution results are passed through the **Privacy Guard** before being returned to the model context. This prevents database queries or web scraper output from introducing external PII into subsequent reasoning turns.

### Tool Execution Timeouts
Operators can configure granular execution timeout windows (e.g. `10,000ms`) per gateway, preventing stalled third-party APIs from hanging agent loops.

### OpenBao Secret Injection
Eluvix integrates with **OpenBao / HashiCorp Vault** secret engines (`/api/secrets/discover`). The Agent Gateway can automatically inject decrypted API keys or bearer tokens into outbound tool requests without exposing credentials in client canvases or client responses.

## Model Context Protocol (MCP)

Eluvix natively supports the **Model Context Protocol (MCP)**, the open standard for connecting AI systems to external data sources, enterprise tools, and local development environments.

### MCP Tool Node (`mcpToolNode`)
The visual editor provides dedicated MCP Tool nodes:
- **Server Endpoint**: Connects via Server-Sent Events (SSE) or local standard I/O (stdio).
- **Execution Modes**:
  - **Automatic (`auto`)**: Executes tool calls immediately upon model request.
  - **Human-in-the-Loop (`confirm`)**: Halts execution and presents a confirmation modal before running potentially dangerous actions.
  - **Dry Run (`dry-run`)**: Simulates tool execution and returns a mocked response for safe evaluation.
- **Parameter Validation**: Automatically verifies model-supplied arguments against JSON schema definitions before network dispatch.

## VectorCraft Art MCP Node (`vectorcraftNode`)

Eluvix includes a first-class **VectorCraft Art MCP Node** that integrates `vectorcraft-cli mcp` (newline-delimited JSON-RPC 2.0 over `stdio`, protocol `2025-06-18`) into the Visual Routing Editor and `@eluvix/router-core`. Agents and LLMs connected to `vectorcraftNode` can inspect documents, draw geometric primitives and cubic Bézier paths, style fills/strokes/gradients, run boolean Pathfinder operations, trace raster images, and export multi-artboard illustrations to `SVG`, `PDF`, `AI`, `EPS`, `PNG`, `WebP`, `PSD`, or `.vectorcraft`.

### Execution Backend Modes
- **Auto (`auto`)**: Attempts to connect once on startup to a live VectorCraft desktop session at `127.0.0.1:7979` and automatically falls back to the in-process headless CPU renderer if no GUI is listening.
- **Remote Desktop GUI (`remote`)**: Passes `--connect 127.0.0.1:7979` to `vectorcraft-cli mcp`, forwarding all 33 tools over the control socket to a running desktop window started with `vectorcraft --control 7979`.
- **Headless CPU Renderer (`headless`)**: Passes `--headless` to run an in-process document model and CPU renderer with no window or display server required (exposes all 27 non-UI tools; UI-only tools `inspect_ui`, `ui_inspect`, `type_text`, `answer_dialog`, `open_panel`, and `ui_screenshot` are automatically filtered out).

### Filesystem Confinement (`--automation-read-root` & `--automation-write-root`)
- Operators can restrict `open_file`, `save_file`, `export`, `document.import`, and `document.place` to explicit directory trees via **Read Root** and **Write Root**.
- Per the upstream VectorCraft MCP specification, passing `--automation-read-root` or `--automation-write-root` to `vectorcraft-cli mcp` implies `--headless` and cannot be combined with `--connect`. When `remote` mode is selected alongside confinement roots, Eluvix's compiler automatically places `--connect <addr>` on `vectorcraft-cli mcp` and emits the `--control <port> --automation-read-root ... --automation-write-root ...` flags for the desktop GUI launch command.

### Built-in MCP Workflow Presets
- **`poster`**: Lay out a poster from a brief using live shapes, gradients, typography, and live effects, verified with `render_preview` before export.
- **`icon-set`**: Build a grid of consistent icons as live vector shapes and inspect alignment across the set.
- **`recolor`**: Recolor selected artwork with explicit colour mappings or `recolor.colors` k-means clustering.
- **`trace-and-style`**: Vectorize a raster image with Image Trace (`trace.create` + `trace.expand`), then apply live effects and recoloring.
- **`export-set`**: Export every artboard across multiple vector/raster formats at once and report format fidelity.

### Context Enrichment & Coordinate / Opacity Guardrails
When `vectorcraftNode` is active on a route, `@eluvix/router-core` injects an `<eluvix-vectorcraft-mcp>` system instruction block and emits `x-eluvix-vectorcraft-mode`, `x-eluvix-vectorcraft-protocol`, `x-eluvix-vectorcraft-tools`, and `x-eluvix-vectorcraft-preset` response headers:
- **Coordinate System**: Document points (`612 x 792` US Letter default, origin `(0, 0)` at top-left of the first artboard, `y` points downward).
- **Opacity Scale Rule**: `doc_inspect` reports both `opacity` (`0..1` fraction) and `opacityPct` (`0..100%`). All drawing and mutation tools (`draw_shape`, `draw_path`, `object.setProps`, `transparency.set`) require `opacityPct` (`0..100`).
- **Atomic Command Batching**: Multi-step illustrations use `command_batch` (`atomic: true`, up to 256 steps) with `"$0.id"` / `"$last.id"` step result interpolation so complex artwork is grouped into a single undo step.

## Native Built-in Tools

Eluvix includes zero-dependency native tools served directly from `/api/v1/tools`:

### 1. Calculator
- Evaluates arithmetic and mathematical expressions securely without executing arbitrary code.
- Ideal for small or fast reasoning models requiring exact numerical precision.

### 2. Web Scraper
- Fetches external URLs, strips boilerplate HTML markup, and extracts clean, readable markdown or plain text.
- Formats extracted content directly into the model's context for summarization or comparative analysis.
