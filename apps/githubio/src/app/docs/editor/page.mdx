# Eluvix Visual Node Routing Editor

The **Eluvix Visual Node Routing Editor** (accessible at `/editor`) is an interactive, Pro Studio graph-based canvas powered by React Flow for designing, auto-laying out, live-simulating, auto-healing, and compiling multimodal routing topologies, agent gateways, and security guardrails.

---

## Pro Studio Capabilities

The **Eluvix Visual Node Routing Editor** combines tactile graph wiring with keyboard-first studio tooling:
- **Spotlight Command Palette (`Cmd/Ctrl + K`)**: Fuzzy-search and spawn any of the 28+ node types at viewport center, switch starter presets, run auto-layout, trigger compilation, or auto-heal graph diagnostics.
- **50-State Undo / Redo (`Cmd/Ctrl + Z` / `Cmd/Ctrl + Shift + Z`)**: Full snapshot history stack across node insertions, parameter edits, edge wiring, deletions, and layout transforms.
- **Deterministic Sugiyama Topological Auto-Layout**: One-click 5-stage left-to-right hierarchical graph layout (`Entry / Guards` &rarr; `Cache / Memory / RAG` &rarr; `Routers / Judges` &rarr; `Gateways / Harnesses` &rarr; `Local & Cloud Upstreams / Observability`) with barycentric edge-crossing minimization.
- **Interactive Live Canvas Route Simulator**: Dry-run prompts with modality, token count, and confidential flags directly on the canvas via `POST /api/v1/route-explain`—animating the winning path in emerald green and dimming bypassed edges in amber with hoverable rejection reasons.
- **One-Click Diagnostic Auto-Fix**: Actionable **"Fix Now"** buttons per lint warning and **"Fix All Issues"** batch healing for disconnected nodes, ungrounded Knowledge Bases, single-point-of-failure upstreams, unguarded cloud PII paths, and circular routing loops.
- **Ergonomic Node Handles & Dynamic Ports**: Enlarged color-coded grab handles, semantic intent ports (`#intent-code`, `#intent-reasoning`, `#tier-local`, `#tier-cloud`), and direct in-card controls.

## Comprehensive Node Catalog

The Routing Editor organizes nodes into functional categories:

### 1. Security Nodes
- **Privacy Guard (`privacyGuardNode`)**:
  - Enforces in-flight PII redaction using `token` (`[REDACTED_API_KEY]`), `asterisk` (`sk-••••`), or cryptographic `hash` (`[HASH:e3b0...]` via SHA-256).
  - Built-in entity filters: API keys, SSNs, credit cards, emails, phone numbers, IP addresses.
  - Exempted Whitelist: Domain and token exemptions (e.g. `internal.corp`, `localhost`).
  - Custom Regex: Configurable user patterns with named identifiers.
  - Audit Logging: Optional logging of redacted fragments for security auditing.
- **Semantic Guard (`semanticGuardNode`)**:
  - Embedding classifier firewall models (DeBERTa-v3, BGE-Small, MiniLM).
  - Sensitivity slider (0.50–0.99).
  - Enforcement actions: `block` (HTTP 400), `strip` (sanitized pass-through), `divert` (quarantine sink), `warn` (audit only).
  - Active threat vectors: Instruction overrides, DAN jailbreaks, system prompt leaks, obfuscated attacks.
  - Custom banned phrases blacklist.

### 2. Routing & Intent Dispatchers
- **Switchyard Router (`switchyardNode`)**:
  - Layer 7 adaptive balancer supporting 5 routing strategies (`cost-complexity`, `cascade-cost`, `lowest-cost`, `lowest-latency`, `round-robin`).
  - Modality-aware media intent routing (`mediaIntentRouting`) isolating ComfyUI synthesis nodes from text chat while steering generative media prompts.
  - Configurable latency spillover circuit breaker (`spilloverThresholdMs`), upstream timeout (`timeoutMs`), and retry counts.
  - Token complexity boundaries and automatic code escalation.
  - Financial governance: per-request cap (`maxCostPerRequest`) and rolling 24-hour cloud spend cap (`maxDailySpendUsd` with `budgetExhaustedAction`: `prefer-local`, `strict-local`, or `reject`).
- **Task Router (`taskRouterNode`)**:
  - Dispatches queries based on semantic intent using Heuristic Regex, FastEmbed Similarity, or Micro-LLM classification.
  - Dynamic intent target handles: `#intent-code`, `#intent-reasoning`, `#intent-fast`, `#intent-tools`, `#intent-default`.
  - Routing modes: Balanced, Lowest Cost, Max Speed, Capability Match.

### 3. Gateways & Proxies
- **Model Gateway (`modelGatewayNode`)**:
  - OpenAI-compatible Bifrost adapter for local and upstream models.
  - In-memory semantic response cache with configurable TTL (seconds) and similarity threshold (`X-Eluvix-Cache: HIT`).
  - Sliding-window RPM rate limiter with automatic HTTP 429 enforcement.
  - Fallback strategies: Cheaper Tier, Same-Tier Alternative, Fail Fast.
  - Global Enterprise System Prompt Prepend.
- **Agent Gateway (`agentGatewayNode`)**:
  - Secures Model Context Protocol (MCP) and Agent-to-Agent (A2A) tool invocations.
  - Access policies: `restrictive` (whitelist only), `permissive` (internal VPC), `open` (public registry).
  - Tool filter modes: `all`, `whitelist`, `blacklist`.
  - Output PII sanitization: Scrubs sensitive data from tool returns before feeding to LLMs.
  - OpenBao Secret Mapping: Directly maps encrypted API keys into tool runtime environments.

### 4. Tools & Observability
- **MCP Tool (`mcpToolNode`)**:
  - Connects external MCP servers via SSE or stdio endpoints.
  - Execution modes: `auto` (immediate), `confirm` (human-in-the-loop), `dry-run` (simulation).
  - Configurable execution timeouts.
- **Observability Node (`observabilityNode`)**:
  - Multi-exporter telemetry engine: Embedded SQLite, OpenTelemetry Collector (OTLP/gRPC), Langfuse LLM Tracing, Prometheus.
  - Trace sampling rate slider (1–100%).
  - PII scrubbing from recorded traces.
  - Full request input/output capture toggle.
  - SLA latency alert threshold (ms).

### 5. Agents & Runtimes
- **Custom Agent (`agentNode`)**:
  - Autonomous persona definitions with system instructions and temperature controls.
  - Primary capability specialization: General, Coding, Research, Orchestration.
  - Persistent multi-turn memory toggle.
- **Agent Harness (`harnessNode`)**:
  - Integrates autonomous runtime engines: `trueforge`, `opencode`, `acp`, `hermes`.
  - Headless tool approval policies: `auto-approve-readonly` (permits reads, halts on writes), `auto-deny`, `surface` (interactive SSE approval prompt).
  - Configurable loop limit (`maxHops`: 1–5) and loop-guard stage compilation.
- **Memory Engine (`memoryNode`)**:
  - Context and long-term memory providers: `openviking`, `mem0`, `sqlite`.
  - Configurable max memory token budget (100–2,000 tokens) prepended in `<recalled_context>`.
  - Privacy Egress Firewall: `cloudMode: "filter"` or `cloudMode: "strip"` to safeguard private memory from third-party cloud leakage.
- **Local Engine & Synthesis Nodes (`ramalamaNode`, `comfyuiNode`, `lemonadeNode`, `vllmNode`, `ollamaNode`)**:
  - **RamaLama (`ramalamaNode`)**: Rootless Podman/Docker OCI inference (`:8080`) with `--rag` artifacts, SELinux isolation, `--network=none` air-gapping, and systemd Quadlet `.container` unit generation.
  - **ComfyUI (`comfyuiNode`)**: Local diffusion, video, and 3D mesh DAG engine (`:8188`) with workflow presets (`flux-txt2img`, `sdxl-txt2img`, `wan21-txt2vid`, `hunyuan3d-mesh`), live VRAM status, local LLM prompt enhancer, and ArtCraft post-processing.
  - **Ollama / vLLM / Lemonade**: Local GPU/NPU-accelerated runtimes with priority scoring, max parallel concurrency, and context window limits.
- **Cloud Providers & Agent CLI Nodes**:
  - Google Antigravity AGY (with first-class **Gemini 4 Carbon** `1M` context & `-low`/`-medium`/`-high`/`-xhigh`/`-max` effort tiers), Billama Cloud, OpenAI Direct, Anthropic Claude Direct, OpenAI Codex, Claude Code.

## Multi-Target Compiler (`compiler.ts`)

Clicking **"Compile & Save"** converts visual graph connections into synchronized configuration artifacts:

| Configuration Artifact | Target System | Description |
| :--- | :--- | :--- |
| `eluvix.json` | `@eluvix/router-core` | Master runtime routing, modality policies, spend caps, guards, and caching |
| `bifrost.yaml` | Bifrost Proxy | Upstream model routing, caching, rate limits, and fallback policies |
| `eluvix-ramalama.container` | Podman Quadlet / systemd | Rootless OCI container unit generated when `ramalamaNode` is present |
| `agent-router.json` | Agent Router | Intent classification engines, routing preference, and intent targets |
| `semantic-router.ts` | Semantic Router | Embedding classifier routes, sensitivity thresholds, and threat vectors |
| `privacy-guard.ts` | Privacy Guard | PII entity detection, redaction styles, whitelist, and custom regex |
| `agent-gateway.json` | Agent Gateway | MCP access policies, tool filter lists, timeouts, and sanitization |
| `observability.ts` | OpenTelemetry / Braintrust | Telemetry collector endpoints, sampling rates, and SLA alerts |
| `antigravity.yaml` | Google AGY | Antigravity agent CLI execution mode, Gemini 4 Carbon effort, and sandboxes |
| `codex.json` | OpenAI Codex | Codex CLI toolchain, reasoning effort, and approval policies |
| `claudecode.json` | Claude Code | Claude Code permissions, tool toggles, and token budgets |

Compiled configurations are saved to SQLite via `POST /api/v1/config` and immediately hot-reloaded without service downtime.
