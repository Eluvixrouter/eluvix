# Paperclip Integration (Switchyard × Agent Org Orchestration)

Eluvix integrates deeply with [Paperclip](https://github.com/paperclipai/paperclip) across three progressive tiers — from zero-code OpenAI-compatible routing (Tier 0) to a full `eluvix_local` OpenCode adapter (Tier 1) and an intelligent Switchyard assignment plugin (`@eluvix/paperclip-plugin`, Tier 2).

---

## Architecture Overview

1. **Tier 0 — Virtual Switchyard Models (`eluvix/*`) & Trajectory Step Tiering**:
   - Point any Paperclip OpenAI-compatible or Anthropic-compatible connection at `http://127.0.0.1:3588/v1` with a `paperclip`-scoped `elx_...` API key—with uniform Paperclip enforcement (`companyIds` `403`, cost/tier ceilings, `x-eluvix-hops`) across `/api/v1/chat/completions`, `/api/v1/messages`, `/api/v1/responses`, `/api/v1/route-explain`, and `DesktopRouterServer`.
   - Select `eluvix/auto`, `eluvix/fast-local`, `eluvix/code-specialist`, `eluvix/heavy-reasoning`, or `eluvix/frontier-verified` from `GET /api/v1/models`.
   - On `eluvix/auto` (or `auto` with `agentStepTiering: true`), intra-heartbeat trajectory analysis classifies tool-call turns (`fast-local`, `code-specialist`, `heavy-reasoning`) and emits `X-Eluvix-Step-Tier`, while non-streaming completions report `usage.cost` alongside `X-Eluvix-Cost-USD`, `X-Eluvix-Correlation-Id`, `X-Eluvix-Paperclip-Priority`, and `X-Eluvix-Paperclip-Bias`.

2. **Tier 1 — `@eluvix/paperclip-adapter` (`eluvix_local`)**:
   - Runs Eluvix's isolated OpenCode harness inside the Paperclip agent's working directory with mid-loop DLP, `x-eluvix-hops` recursion protection, `SecretRef` (`env:`, `file:`, `bao:`, `vault:`, `keychain:`) HMAC signing via `signOutboundPaperclipHeaders`, and `x-paperclip-*` priority, budget-pressure, and sensitivity headers.
   - Supports mid-run virtual tier escalation (`escalateOnFailure`, `fast-local` &rarr; `code-specialist` &rarr; `heavy-reasoning` &rarr; `frontier-verified`) on HTTP `429`/`5xx` without mutating agent configuration.
   - Queries `GET /api/v1/paperclip/usage/:runId` after each run to report authoritative token counts and `costStatus: "reported"` USD spend.

3. **Tier 2 — `@eluvix/paperclip-plugin` (`eluvix.switchyard`)**:
   - Exposes five Switchyard tools (`eluvix:capabilities`, `eluvix:classify_task`, `eluvix:recommend_assignee`, `eluvix:explain_route`, `eluvix:budget`), matching MCP tools (`switchyard_*`), and host UI actions (`eluvix:approve_assignment`, `eluvix:dismiss_assignment`, `eluvix:assign_candidate`, `eluvix:explain_route`, `eluvix:reset_safety_fuse`).
   - Classifies task complexity, modalities, and PII sensitivity, scores candidate employees across SQLite-cached `/v1/embeddings` semantic fit (`paperclip_embedding_cache`), decayed cost-weighted Beta posteriors, 7-day budget exhaustion forecasts (emitting `paperclip.budget_forecast` webhooks), live `openIssueCount` load, and `reportsTo`/parent hierarchy affinity.
   - Supports `off | advisory | shadow | auto | auto-with-approval` assignment modes (with pending approval proposals persisted in `ctx.state`, a circuit-breaking Auto-Assign Safety Fuse that downgrades `auto` &rarr; `auto-with-approval` on repeated task failures, and 48h outcome feedback) plus bundled React UI slots (`taskDetailView`, `page` `/switchyard`, `dashboardWidget`, `sidebar`, `detailTab`).

## Security, Memory Partitioning & Scoped Key Governance

- **`SecretRef` HMAC Context Signing (`X-Paperclip-Context-Ts`, `X-Paperclip-Context-Sig`)**: Resolves `hmacSecret` via `env:`, `file:`, `bao:`, `vault:`, and `keychain:` pointers without ever falling back to literal reference strings. When `requireSignedContext: true`, tampered, expired, or unsigned bias headers are untrusted, dropped, and audited via `paperclip.hmac_rejected`.
- **Company/Issue Episodic Memory Sub-Partitioning**: Scopes Paperclip recall and writes to `` `${userId}::pc:${companyId}` `` (`viking://user/${userId}/pc/${companyId}/...`), boosting memories sharing the active `issueId` while blocking cross-company memory leakage.
- **Admin Scoped Key & Policy Manager (`/api/v1/keys` & `/configurator`)**: Mint, inspect (with masked `hmacSecret` literals and visible `SecretRef`s), and revoke `elx_...` keys carrying `paperclip: { companyIds, maxTier, maxCostPer1kUsd, hmacSecret, allowUnsignedContext }` caps.
- **Governance Webhooks & Long-Horizon Rollups**: Emits SSRF-guarded webhooks (`paperclip.budget_forecast`, `paperclip.tier_escalated`, `paperclip.hmac_rejected`, `paperclip.safety_fuse`) and retains daily summaries in `telemetry_daily_rollups` across `DELETE /api/v1/observability?olderThanDays=30` pruning.

## Visual Configuration, Route Simulator & Golden Evals

In the **Eluvix Visual Node Routing Editor**:
- Add the **Paperclip Bridge** node (`paperclipBridgeNode`) from the Command Palette (`Cmd/Ctrl+K`) to configure **Paperclip Base URL** + interactive **Probe** (`POST /api/v1/paperclip/health`), **Priority Policy**, **Budget Pressure Threshold**, **Sensitivity Floor**, `SecretRef`-aware **HMAC Signing** status badges, and `requireSignedContext`.
- Use the **Route Simulator** drawer to test prompts with Paperclip `companyId`, `priority`, `budgetRemainingPct`, and `sensitivity` overrides, or run the built-in `paperclip-org-governance` Golden Eval suite (`POST /api/v1/evals/run` or `npx eluvix-eval`).

Verify the full local integration offline at any time with `node scripts/paperclip-e2e.mjs`.
